# JS Drum Kit

A simple browser-based drum kit built with HTML, CSS, and JavaScript. Press the displayed keyboard keys to play different drum sounds with animated visual feedback.

## How to Run

Open [index.html](./index.html) in a web browser.

## Key Bindings

`A` Clap · `S` Hi-hat · `D` Kick · `F` Open hat · `G` Boom · `H` Ride · `J` Snare · `K` Tom · `L` Tink

## Project Structure

- `index.html` — Drum kit markup and keyboard interaction
- `style.css` — Layout and visual styling
- `sounds/` — Audio files used by the kit
- `background.jpg` — Page background image
